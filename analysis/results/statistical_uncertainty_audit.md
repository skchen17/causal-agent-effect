## Threshold Audit

- `LOTO FNR, deployed FNR, baselines, contrastive post-FNR, causal-chain FNR`: clf.predict(...), effectively the default 0.5 probability/logit decision boundary for binary classification
  Risk: No threshold sweep or validation-selected threshold is recorded in current artifacts. FNR/FPR should be reported as default-threshold diagnostics, not calibrated deployment estimates.
- `pIIA raw intervention outcomes`: score_before <= 0.5 < score_after
  Risk: This is a probe-threshold crossing diagnostic. It does not establish standard SCM-based interchange intervention validity.
