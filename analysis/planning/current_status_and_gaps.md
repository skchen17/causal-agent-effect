- A repaired mainconf v2 dataset now exists with 932 rows: 459 original rows, 408 rule-based increment rows, and 65 static replay trace rows.

- v2 strict LOPO contrastive evidence is weaker than full-training repair: 2 evaluable effects, 68 tool-case rows, 33/68 improved, mean delta FNR = 0.1044.

- Auth-SafeInv T53 repairs the v1 unauthorized surface graph sparsity at the data level: v2 has 1464 rows and all 7 focus effects now have at least 3 unauthorized tool surfaces.

With validation-selected thresholds, execution-trace present verification reaches held-out test FNR=0.0/FPR=0.0 (N+=197, N-=1170), while static verifiers have held-out test FNR=0.6294/FPR=0.0462. T64 is now full-precision Qwen3-8B, but it remains non-provider-backed live/protocol evidence.
- T65 adds actual headless Chrome file-backed browser-runtime traces: 120 traces and 960 candidate-effect rows. With validation-selected thresholds, execution verification reaches held-out test FNR/FPR=0.0/0.0, while static verifiers have FNR/FPR=1.0/0.0. It closes part of the browser-runtime gap, but not HTTP browser networking or deployed-agent runtime validation.
- T68 aggregates T62 validation-selected candidate-effect predictions into action-level allow/deny decisions. It improves monitor-facing validity but weakens over-simple row-level interpretation: execution verification allows zero unauthorized actions on T61 provider and T65 browser-runtime traces, yet falsely denies all authorized held-out actions under the current threshold. T68 therefore supports the need for action-level policy evaluation before any deployment-facing claim.
- T69 shows the execution-verifier full-label upper bound relies on structured trace evidence: hiding `verified_effects`, `effect_diff`, `unauthorized_effects`, and related fields increases mean held-out FNR from 0.0353 to 0.1162 after adding T65. A stricter minimal-evidence view degrades to mean FNR 0.1465.
- T70 separates the framework from simpler proxies. Pre-action rule-only and provenance-only baselines are substantially weaker, but a handcrafted raw-status boundary is competitive on controlled traces. This narrows the novelty claim to effect-level verification/evaluation framing and policy calibration, not universal superiority over all status-rule defenses.
- T73 tests action-level threshold calibration. Under a validation false-denial target of 0.10, several trace families choose all-allow thresholds and therefore have held-out unauthorized action allow=1.0. This is a negative calibration result, not a deployable policy.

Do not claim:

- deployed agent safety certification;
- observed real-agent execution validation;
- direct real-agent handler/API execution validation from T59;
- causal-chain conditioning prevents task overreach;
- full-training contrastive projection solves unknown-tool or coverage-missing mitigation;
- strict LOPO success for two-form effects;
- broad context/language/semantic reframing coverage beyond tool-surface experiments.

## 4. Recommended Next Phase

Current paper status is **Borderline / Major Revision** for a main conference if framed as a verifier-assisted controlled study. T59 improves tool-code grounding but adds a negative stress result, T61 strengthens provider API evidence, T62 fixes threshold calibration for tested trace datasets, T63 broadens controlled web/search/browser/messaging local-adapter coverage, T64 adds key-free live HTTP plus local protocol messaging evidence, and T65 adds file-backed headless Chrome runtime traces. Immediate next tasks:

1. Add provider-backed search/SaaS messaging/HTTP browser automation or deployed-runtime traces when credentials/runtime access are available.
2. Develop non-degenerate action-level calibration or abstention policy beyond T73's simple thresholding.
3. Replace deterministic full-label/raw-evidence verifiers with independent learned or formally specified effect verifiers.
