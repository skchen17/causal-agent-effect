# 路径一知识体系：因果抽象 + 线性约束

## 学习目标

理解并能够应用因果抽象理论来分析（最终是设计）agent 安全系统中的可解释因果表征。

---

## 第一层：因果抽象的直觉基础

### 1.1 核心问题

因果抽象试图回答一个看似简单但极其深刻的问题：

> 一个神经网络的计算是否"实现"了一个人类可理解的高层因果模型？

这不是"模型输出是否正确"——那是行为评估。因果抽象问的是"模型内部的因果机制是否与一个可解释的算法一致"。

### 1.2 关键直觉：交换干预

假设你有一个高层因果模型（比如"判断两个等式是否等价"的算法），你想验证一个神经网络是否在内部实现了这个算法。

**交换干预（Interchange Intervention）** 的做法：

1. 在神经网络的内部激活中，选择一个区域假设它"编码"了高层变量 V₁（比如"第一对是否相等"）
2. 取一个"基准输入"（如 "AABB" → 前两个相等，后两个相等）和一个"源输入"（如 "ABCC" → 前两个不相等，后两个不相等）
3. 将基准输入中"对应 V₁"的激活值**替换**为源输入中"对应 V₁"的激活值
4. 看输出：如果神经网络的行为与高层模型中"V₁ 被干预为不等"的预测一致，那么你对齐映射就是有效的

**本质**: 交换干预是一种**内部的因果实验**——不改变输入，只改变内部表征，然后验证行为是否符合因果模型的预测。

## 第二层：分布式对齐搜索 (DAS)

### 2.1 核心问题

第一层的因果抽象假设对齐映射是"局部"的——每个高层变量对应一组不相交的神经元。但真实的神经网络表征是**分布式的**——一个概念可能散布在整个激活向量的不同维度上。

DAS 解决了：**如何在分布式表征中找到高层因果变量的对齐？**

### 2.2 核心方法

DAS 的核心是一个**可学习的正交旋转矩阵 R**：

1. 取激活向量 h ∈ ℝᵈ
2. 用正交矩阵 R 旋转到一个新的基：y = Rh
3. 在旋转后的空间中，选择特定的维度区间作为"该高层变量的子空间"
4. 在这些维度上做交换干预
5. 用 R⁻¹ 旋转回原始空间
6. 验证输出是否与高层模型的干预预测一致

**关键**: R 是通过梯度下降学习的——优化目标是交换干预的准确率。

### 2.3 为什么正交矩阵

正交矩阵（RᵀR = I）保证：
- 旋转不改变向量的模长（‖Rh‖ = ‖h‖）——不会放大或缩小信息
- R⁻¹ = Rᵀ ——计算高效
- 旋转后的各维度仍然独立——便于划分子空间

### 2.4 入门读物

## 第三层：非线性表征困境

### 3.1 核心发现

Sutter et al. (NeurIPS 2025 Spotlight) 证明了：

> 如果对齐映射 τ 可以是非线性的，那么任何神经网络（包括随机初始化的）都可以被完美对齐到任何高层因果模型。因果抽象变得空洞——不能区分真正的因果理解和伪造的解释。

### 3.2 为什么

非线性对齐映射 τ 本质上是一个通用的函数逼近器。给定足够复杂度的 τ：

- τ 可以从随机噪声中"解码"出任何你想要的因果结构
- 交换干预的高准确率不再证明因果抽象是真实的——它只是证明了 τ 足够灵活

类比：
- **线性 τ**: 一个高倍率显微镜——你只能看到物体上本来就有的细节
- **非线性 τ**: 一个 AI 图像生成器——你可以"看到"任何东西，因为生成器自己画上去了

### 3.3 为什么是线性

线性约束 τ(x) = Wx + b 的力量在于**有限容量**：
- 线性映射只能提取激活中**线性可编码**的信息
- 如果某个因果概念在激活中没有被线性编码，线性 τ 就无法恢复它
- 因此，线性 τ 的成功 = 激活确实包含该因果概念（有意义的发现）
- 线性 τ 的失败 = 激活不包含该因果概念（可证伪的零结果）

### 3.4 入门读物

1. **Sutter et al. (NeurIPS 2025 Spotlight)** — *"The Non-Linear Representation Dilemma"*
   - arXiv: 2507.08802
   - 读摘要 + 第 3 节（形式证明）+ 第 4-5 节（实验）
   - 特别关注图 1：随机模型 + 非线性 τ = 100% IIA

2. **Engels et al. (2024)** — *"Not All Language Model Features Are Linear"*
   - arXiv: 2405.14860
   - 注意：这不是反对线性的论文，而是论证"有些特征确实是多维度的但不是非线性的"
   - 关注"圆形表征"（circle representations）的例子

3. **Ravfogel et al. (NeurIPS 2025)** — *"Emergence of Linear Truth Encodings in Language Models"*
   - 解释为什么线性表征会出现——来自共现统计
   - 提供"线性表征不是魔法"的机制解释

## 第四层：线性表征假说 (LRH)

### 4.1 核心命题

> 神经网络（特别是语言模型）倾向于将概念编码为激活空间中的线性方向。

具体来说：
- "主语是男性"这个二元概念 = 激活空间中的一条直线方向
- 沿这个方向移动 a → a + λv 会单调地改变模型输出中的"男性化"程度
- 这已被广泛验证：情感分析、事实性、诚实度、语种等概念都可以用线性探针恢复

### 4.2 LRH 的微妙之处

2024-2025 年的研究揭示了一个更微妙的图景：

1. **不是所有特征都是线性的**（Engels et al., 2024）：有些特征天然是多维的（如环形的"星期几"表征）
2. **线性表征需要足够的数据频率**（Merullo et al., ICLR 2025）：主客体在预训练数据中需要共现 1k-4k 次才能形成线性表征
3. **线性表征是两阶段涌现的**（Ravfogel et al., NeurIPS 2025）：先记忆个别事实，再涌现线性分离
4. **但线性约束仍然是因果可解释性的必要条件**（Sutter et al., 2025）：这与 LRH 是否 100% 成立无关——即使有些特征不是线性的，线性约束仍然是保证因果抽象有意义的必要条件

### 4.3 入门读物

1. **Park et al. (2023/2024)** — *"The Linear Representation Hypothesis and the Geometry of Large Language Models"* 
   - 综述性质，适合建立整体理解

2. **Merullo et al. (ICLR 2025)** — *"On Linear Representations and Pretraining Data Frequency"*
   - arXiv: 2501.xxxxx
   - 频率阈值与线性表征形成的定量关系

**关键概念清单**:
- [ ] 线性探针是什么以及为什么它有效
- [ ] LRH 的证据和支持
- [ ] LRH 的已知限制（环形表征、多维特征）
- [ ] LRH 与因果抽象的关系：LRH 是一种经验发现，线性约束是数学必要性——它们是不同的东西

## 第五层：应用于 CAR（初步框架）

### 5.1 核心研究问题

> 在 agent 安全系统中，当我们从执行历史中学习因果表征时，这些表征是否满足线性可解释性条件？如果不满足，我们需要什么约束来保证它们是有意义的？

### 5.2 具体的研究操作

```
Step 1: 定义高层因果模型
  CAR 的高层因果变量 = 因果效果集合
  {command_executed, file_written, file_deleted, message_sent, ...}
  以及它们之间的关系（d-separation, 方向性）

Step 2: 获取低层表征
  从 CAR 的潜空间编码器（或 LLM 的隐藏状态）中提取激活值

Step 3: 寻找线性对齐
  用 DAS 的方法，学习一个正交旋转矩阵 R
  使得旋转后的子空间维度线性对应到因果效果变量

Step 4: 验证因果抽象
  用交换干预：
  - 基准执行（write_file → file_written 应该发生）
  - 源执行（read_file → file_written 不应该发生）
  - 交换两者的"file_written 子空间"激活
  - 验证行为是否符合因果模型的预测

Step 5: 检验线性约束
  对比线性 τ 和非线性 τ 的 IIA：
  如果非线性 τ 显著优于线性 τ，说明潜空间没有线性编码因果信息
  这意味着因果解释是不可靠的

Step 6: 审计验证
  对通过线性验证的因果维度
  检查它们在 ProofObject 审计链中的预测-实际一致性
```

### 5.3 一个具体的研究假设

> **假设**: 在 agent 安全系统中，只有当工具效果（如 `command_executed`）在潜空间中被线性编码时，基于该表征的安全预测才具有可审计的可靠性。非线性编码的效果虽然可能被 CRL 模型隐式地学到和利用，但其解释是空洞的——不能用于安全审计。

**验证方法**: 
- 训练线性探针预测每个因果效果 → 记录 R²
- 训练非线性探针（MLP）预测同一效果 → 记录 R²
- 对比两者：Δ = R²_nonlinear - R²_linear
- 如果 Δ 很大 → 该效果不是线性编码的 → 基于它的安全解释不可靠
- 如果 Δ 很小 → 该效果被线性编码 → 安全解释可验证
