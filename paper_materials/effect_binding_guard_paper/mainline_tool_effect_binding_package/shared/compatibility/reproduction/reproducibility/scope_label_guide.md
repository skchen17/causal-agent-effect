# Scope Label Guide

- `baseline`: No deployable safety claim.
- `paper_grade_custom_stress`: Paper-grade for local stress only.
- `official_method_custom_stress`: Not original-paper benchmark reproduction.
- `original_component_custom_stress`: Component evidence only.
- `original_pipeline_local_model`: Feasibility only when no-defense utility/ASR is low.
- `diagnostic`: Not original method or deployable guard.
- `upper_bound`: Not deployable.
- `audited_custom_stress`: Valid for E47 counterfactual claims.
