# 实验目录

本目录按论文要回答的证据问题划分为 11 个实验族，而不是按历史实验编号划分。每个实验族实际保存相关源码、评测数据、结果、报告、脚本、测试或运行记录，并提供单独的中文 `README.md`。

- `binding-failure-and-granularity`：工具效果绑定失效与粒度瓶颈。
- `precommit-authorization-and-audit`：预提交授权原型及审计。
- `independent-contracts-and-realistic-traces`：独立合约、真实格式轨迹和机制分解。
- `counterfactual-descriptor-onboarding`：效果描述生成、反事实筛选和注册。
- `real-model-and-checkpoint-evidence`：真实模型和发布检查点补强。
- `intent-bound-runtime-guard`：任务意图、权限包络和运行时守卫。
- `unified-agent-security-baselines`：统一 AgentDojo 强基线比较。
- `long-horizon-transfer`：长任务跨环境迁移。
- `security-analysis-ablation-and-overhead`：安全模型、消融、自适应攻击和开销。
- `human-authority-and-causal-validation`：人工权限审查和因果效果验证。
- `adaptive-injection-benchmark`：增强代理注入评测数据。

历史编号仍可能出现在 artifact 文件内容中，用于论文数字和旧报告追溯，但不再作为目录名。
