# 人工权限审查与因果验证

## 目的

通过人工审查权限清单和受控干预验证安全相关效果投影。

## 流程

生成匿名 review packet，验证填写完整性，并把人工判断与系统投影和中介结果进行比对。

## 包含内容

- **权限清单人工审查**：为 AgentDojo 工具与任务建立可审计的 authority manifest，并收集独立人工确认。
- **因果效果投影验证**：验证实际调用到安全相关效果投影的因果对应关系，并对投影清单做人工审查。
- **有限域效果绑定验证**：对 5 个 AgentDojo 工具的 54 个有效调用进行穷举执行，用前后状态独立构造具体效果，并检查不同 atom 表征是否产生可分授权碰撞。公共字段 contract 有 118 个碰撞对；带类型限定符的已审查 contract 在该有限域内为 0。

## 结论边界

可信状态取决于真实审查材料；只支持已覆盖工具、任务和干预轴。有限域零碰撞不代表开放工具域或其他权限语言中的全局完备性。
