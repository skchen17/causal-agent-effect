# 任务意图绑定与运行时守卫

## 目的

验证固定 atom 描述、任务权限包络、动态重规划和 effect-diff guard 在多步代理执行中的作用。

## 流程

从字段必要性开始，生成任务权限范围，在调用差异出现时重规划，并逐步进入完整 AgentDojo runtime。

## 包含内容

- **原子字段必要性运行时验证**：修正简单字段变化即视为通过的问题，改为验证字段对效果和安全控制是否必要。
- **任务权限包络运行时**：让 agent 在任务开始时给出预期效果与权限范围，运行时比较实际调用。
- **意图绑定与动态重规划**：当多步调用超出初始权限包络时，把精确差异反馈给 LLM 决定继续、修改或停止。
- **语言模型描述符代理运行时**：在完整 AgentDojo 流程中测试由 LLM 识别工具效果并注册 descriptor 的方案。
- **效果差异运行时守卫**：通过计划效果与实际工具调用效果的差异实现更完整的运行时中介。

## 结论边界

运行时结果依赖初始意图解释、descriptor 完整性和工具适配；不声称生产部署安全。
