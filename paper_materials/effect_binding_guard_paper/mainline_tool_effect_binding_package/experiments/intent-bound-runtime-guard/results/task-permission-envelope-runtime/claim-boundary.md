E72 evaluates a saved-replay architecture in which tool atom descriptors are fixed before runtime, a local LLM generates a task-level permission envelope from the user task, and deterministic code checks whether the concrete tool call stays within that envelope. The LLM does not make runtime allow/deny decisions and does not see labels, sidecar atoms, expected decisions, or violation reasons. Labels and sidecar atoms are used only for offline scoring. This is not production-safety or deployed-agent evidence.
