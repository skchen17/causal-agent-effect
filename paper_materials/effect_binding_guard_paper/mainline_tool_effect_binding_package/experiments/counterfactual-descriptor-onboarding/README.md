# 效果合约生成与反事实注册

## 目的

研究如何由工具描述产生 atom descriptor，并通过反事实反馈筛选后注册到确定性运行时。

## 流程

从确定性原型、本地 LLM 生成和迭代修正，发展到字段敏感性、候选筛选和 descriptor runtime guard。

## 包含内容

- **效果合约注册原型**：演示工具效果描述从候选合约、反事实验证、修正、冻结到确定性运行时授权的完整链路。
- **本地语言模型效果合约生成**：测试本地 LLM 能否为留出工具提出结构化效果合约，并通过严格冻结门禁。
- **迭代反事实合约修正**：测试本地或远程 LLM 候选合约能否通过净化后的反事实失败反馈逐轮改进。
- **语言模型字段反事实敏感性**：直接测试 LLM 在干净与注入上下文中对关键字段变化的 atom 和决策响应。
- **反事实筛选原子描述**：让 LLM 提出候选 atomized descriptors，并按反事实压力结果进行 top-k 选择。
- **反事实引导原子描述运行时守卫**：离线生成并验证工具 atom descriptor，运行时由确定性 guard 做授权。

## 结论边界

未通过严格门禁的候选只能称为实验描述符，不能称为自动生成的安全合约。

目录名按实验内容命名。历史实验编号只保留在原始 artifact 内容和兼容路径中，不再作为目录名。
