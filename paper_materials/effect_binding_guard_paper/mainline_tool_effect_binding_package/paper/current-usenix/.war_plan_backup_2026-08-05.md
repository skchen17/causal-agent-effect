## 4.5 论文质量评估与审稿风险（2026-08-03 paper-reviewer 全新评审）

**总体推荐：Borderline**（weak reject ↔ weak accept，重心偏下沿；置信度 ~0.65，取决于审稿人构成）。

### 逐维度评分
创新 7 / 技术 8 / 实验设计 6 / 写作 7 / 影响力 5.5 / 可复现性 6。

### 三大缺口（决定最终结果的核心）
1. **效用 63→33/97、180→87**（严重度高、被攻击概率高）："安全增益来自保守拒绝"的替代解释是最大风险。缓解：写作上把损失归因于接口覆盖缺陷（pathway audit 已有证据）+ 前沿定位（优于 PromptArmor 效用、强于 Sandwiching 安全）。
2. **单一模型 Qwen3-32B Q4_K_M**（严重度高、概率高）：只能靠写作收缩外推主张 + 后续补第二模型。
3. **原子粒度机制归因缺口**（严重度高、概率高）：321-case 适用性子集是唯一证据；**V0–V3 归因实验是唯一能把重心推向 weak accept 的实验**。若 V0–V3 零差异 → 论文须收缩为表征义务+方法论+feasibility runtime（当前 claim boundary 已兼容，损失可控）。

### 可立即执行的低成本改进（现在就能做，已核实）
1. Abstract 数字过载（一段 11 个数字）→ 减数：保留 1 个表征结果 + 主 ASR + 迁移结果，其余入正文。
2. Abstract/Intro 加一句"frozen profile 结果不实例化 O1–O5 全部前提"（拆分系统结果与定理实例化）。
3. **Table (a) v1.1.2 vs (b) v1.2.1 版本差异需补说明**（已核实 `table_granularity_and_transfer.tex` 两面板版本不一致）。

### 三个必答问题的结论（供决策引用）
- **a) v17 与 E78 一致能否支撑 Cycle 1？** 条件性支持：换数+claim map+URL 时间可行，但**不提升评审重心**（效用/单模型/归因三缺口仍在），预期仍 Borderline。
- **b) V0–V3 结果影响**：正结果 → 上调系统主张冲 weak accept；零/负结果 → 收缩定位（已与现 claim boundary 兼容）；混合结果（V3>V2 但≈V1）→ 写作成本最高。
- **c) 33/97 可辩护策略**：归因式辩护（pathway audit 定位接口缺陷）+ 前沿定位（competitive frontier, not dominated）+ 覆盖归一化（26-task 编译子集 20→15/26 报告接口质量）+ 诚实换信任；禁止 overclaim。

**结论：写作与合规性已达线，科学性处于 borderline 线上下；最缺 (a) V0–V3 归因证据 (b) 效用主张重定位。**

## 4.6 ACCEPT 路径分析（2026-08-03，见 `accept_path_analysis_2026-08-03.md`）

**核心判断：缺的不是多个中等信号，而是"一个强信号"**——任一维度推到"审稿人必须承认"的强度即可跨线。

### 接受判据（4 条）
J1 无致命伤（必要条件，缺则必拒）/ J2 一个强贡献 / J3 验证完整性 / J4 影响力潜力。当前 J1 大部分关闭、J3 理论侧强，J2 接近未达、J4 最弱。

### 三个战略方案（成功概率为主观估计）
- **A 理论-方法论主导**（~0.25-0.3）：N1+T1+T2+T3+E2+N3；对赌理论审稿人；失败降 weak accept
- **B 系统效能主导**（~0.45-0.55）：V0-V3 全量+E4+E1 全量+N2+E5+E2；三缺口同转正；资源 105-165 GPU h
- **C 均衡框架（推荐执行框架）**（~0.35-0.45）：低成本项先行 → v17+V0-V3 → 按结果分流 A/B → Artifact

### V0-V3 决策树（根=归因实验）
- **正**（V3 显著优于 V0/V1/V2 + H4 非拒绝 + H5 ≥3 suite/strata）→ 走 B，唯一可直接瞄准 accept 的分支
- **零/负** → 走 A；**诚实判断：此分支下 accept 不现实（≤0.15-0.2）**，现实目标 = weak accept + 转投
- **混合**（V3>V2≈V1）→ 最贵分支：N2 细分 + N3 局部 + E2 判断是否因 power-set family 过强

### 白皮书项调整
**升级为必须**：E2（粗 policy 族，CPU 近零，唯一无论正负都加分的实验）、T2（定理扩展+O6）、E1（至少 160-subset）；**降级**：E3 adaptive、E84 人类评审。

### 如果只能做 3 件事（边际贡献最大）
1. **V0-V3 4×726 预注册归因全量**（70-110 GPU h）——唯一把粒度归因升为全量证据的实验，决定叙事分叉
2. **E4 authority/resolver 覆盖 pilot**（10-20 GPU h + 工程）——正面进攻最大 reject 触发面（效用），恢复 5+ 任务即可弱化"保守拒绝"解释
3. **E1 第二模型**（25-35 GPU h，至少 160-subset）——关闭单模型缺口，与 V0-V3 共用协议，边际成本最低
