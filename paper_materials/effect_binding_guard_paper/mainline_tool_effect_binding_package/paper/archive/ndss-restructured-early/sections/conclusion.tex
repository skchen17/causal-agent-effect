\section{Conclusion}

This draft reframes LLM-agent tool safety around tool-effect binding: before a side-effectful action commits, the mediator must bind the candidate call to the realized effect, target resource, operation mode, authorization context, and provenance/control source. Counterfactual stress tests show that existing methods are not simple tool-name classifiers, but still fail joint binding. A reference hard guard improves some tradeoffs while exposing resource/authorization as the dominant bottleneck. An authorization-aware local pre-commit prototype shows that explicit atom expansion and authorization context can substantially improve controlled mediation, reducing unsafe pre-allow to zero under E55-v2 strict labels while raising coverage relative to the earlier hard guard. The result is a measurement framework and local feasibility probe, not a production safety guarantee. The next step is independent held-out contracts and realistic replay domains that test whether the atom interface transfers beyond the current controlled package.
