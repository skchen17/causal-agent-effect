# Scope Labels

- `baseline`: Non-method baseline or simple proxy.
- `official-checkpoint custom stress`: Released checkpoint on E47/E48 custom stress, not original benchmark reproduction.
- `component custom stress`: Original component or policy logic under custom structural stress.
- `original-pipeline local-model feasibility`: Pipeline compatibility with local model, not original-paper numeric reproduction.
- `method-feasibility custom stress`: E48/E50 hard guard under controlled custom stress.
- `diagnostic`: Mechanism or negative diagnostic, not a main method claim.
- `oracle`: Uses gold labels or otherwise non-deployable information.
- `upper bound`: Non-deployable upper-bound comparison.
- `evaluation-only controlled stress`: Constructed stress data requiring audit before main audited claims.
