# Introduction Outline

- Agent safety failures are ultimately about realized effects on resources under an authorization context.
- Tool names, schemas, wrappers, planner formats, and trace labels are unstable surfaces.
- Surface robustness is necessary but insufficient: a guard must jointly bind effect, resource, authorization, provenance, evidence, and utility.
- E47 contributes a stress-test framework, audited counterfactual lattice, cross-method measurements, structured-defense diagnostics, and claim-boundary discipline.
