# Section Blueprints

## Controlling Structure

1. A structured tool call may commit several independently authorizable effects.
2. A monitor cannot recover policy distinctions erased by its input representation.
3. Source-executed counterfactuals can falsify and refine a policy-relative effect representation before registration.
4. A frozen descriptor can drive deterministic pre-commit mediation, provided provenance, policy, complete mediation, and check–use assumptions hold.
5. The current C1f implementation is a narrow provenance-origin instance, not a complete authority system.

## Abstract

Move from compound effect problem to collision theorem, counterfactual registration, finite and held-out source evidence, conservative registry disclosure, bounded runtime result, baseline parity, and claim boundary. Insert pending final results only through generated tables and the claim reproducer.

## 1. Introduction

Use the calendar example to establish independent effects. Explain why tool names, raw arguments, and defaults/pre-state differ as security views. Define tool-effect binding and policy-relative atoms in prose. Explain counterfactual falsification before runtime. Describe C1f in one bounded paragraph. End with three contributions that map exactly to representation, registration, and mediation evidence.

## 2. Related Work

Organize by question rather than chronology:

- prompt injection and provenance attribution: whether untrusted content influenced a call;

Do not claim external-system benchmark reproduction.

## 3. Problem and Security Model

Define authenticated task, untrusted observation, structured call, committed effects, adversary, enforcement point, provenance-origin objective, TCB, and non-goals. Explicitly exclude output-only goals and global ACL decisions from the implemented theorem.

## 4. Counterfactual Effect Binding

Start with one atom example. Define execution context, concrete effect sequence, and relative minimality. Present offline registration as propose, execute interventions, compare committed state, refine/retain, and freeze. Disclose 67/67 retention. Present runtime structured provenance, per-leaf field checks, effect expansion, tri-state decision, and exact-signature execution.

## 5. Security Analysis

State authorization sufficiency. Prove the representation-collision tradeoff. Define a source-executed counterexample and finite refinement termination. State C1f's two allow conditions and prove conditional provenance-origin confinement. Keep all assumptions explicit.

## 7. Results

Present findings in causal order:

1. compound effects occur in benchmark trajectories;
2. coarse views create authorization-separating collisions;
3. finite refinement and held-out typed effects remove observed collisions;
4. broad registration remains conservative and partially unresolved;
5. C1f provides auditable bounded mediation but does not dominate Spotlighting;
6. granularity diagnostics distinguish selectivity, while current transfer establishes or falsifies portability;
7. final repeated, second-model, and held-out outcomes determine external-validity strength.

## 8. Limitations and Conclusion

Limit descriptor soundness, provenance assumptions, literal canonicalization, policy scope, low baseline ASR, and transfer. Conclude with the representation obligation and executable falsification method, not a universal defense claim.
