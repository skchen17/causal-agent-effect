# 论文目录

- `current-usenix`：当前 USENIX Security 主稿及可编译 PDF。
- `compact-usenix`：压缩版候选稿。
- `flat-usenix`：单文件整理版。
- `archive`：历史 NDSS 稿和早期论文草稿。
- `assets`：论文图表与共享图表材料。
- `source-materials`：写作和方法材料。
- `writing-workspace`：PaperSpine 写作、证据映射与审计产物。
- `project-notes`：旧根目录中的写作状态和 claim-boundary 文档。

当前主稿可在 `paper/current-usenix` 中直接运行 `latexmk -pdf main.tex`。
